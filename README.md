# 小テストジェネレータ

**CSV/TSVから小テストと解答用紙を作成できる、ローカル動作のWebアプリケーションです。**

単語帳などの学習データを読み込み、出題範囲・問題数・出題形式を指定するだけで、印刷用の問題用紙と解答用紙を生成できます。HTML・CSS・JavaScriptのみで動作し、サーバーの構築やアカウント登録は不要です。

## 開発背景

小テストを作成する際、教材から問題を選び、順序を調整し、問題用紙と解答用紙を整形する作業が発生します。本アプリは、こうした繰り返し作業を減らし、CSVで管理した学習データから必要な範囲のテストを手軽に作れるようにすることを目的として開発しました。

特に、複数のPCで利用する場面を想定し、追加ソフトウェアやサーバーに依存しない構成を採用しています。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| CSV/TSV読み込み | ローカルの学習データを読み込む |
| 出題範囲・問題数指定 | 必要な範囲から指定数の問題を抽出する |
| ランダム出題 | 問題の順番をシャッフルする（オフにも変更可能） |
| 英語・日本語の双方向出題 | 英→日、日→英を切り替える |
| ライブプレビュー | 設定に応じた印刷イメージを表示する |
| 問題・解答用紙の生成 | 問題のみ、解答のみ、両方の印刷に対応する |
| 一括生成 | 指定範囲をブロックに分割して複数のテストを作成する |
| 社会モード（調整中） | 問題文・解答形式や、章・節・項による範囲指定を試験実装中 |

## 使い方

### 1. 起動する

このリポジトリをダウンロードまたはクローンし、`index.html` をブラウザで開いてください。

```bash
git clone https://github.com/atemi72/Word-Test-Generator.git
cd Word-Test-Generator
```

追加ライブラリのインストールやWebサーバーの起動は必要ありません。比較的新しいデスクトップブラウザでの利用を想定しています。ブラウザによってファイル選択や印刷の動作が異なる場合があります。

### 2. 学習データを用意する

例えば、次のようなUTF-8形式のCSVファイルを用意します。

```csv
英語,日本語
apple,りんご
book,本
network,ネットワーク
computer,コンピュータ
```

通常の英単語モードでは1列目を英語、2列目を日本語として扱います。上のような既知の列名を持つヘッダーのほか、ヘッダーなしの2列データも扱えます。独自の列名を使う場合、先頭行がデータとして扱われることがあるため注意してください。

### 3. テストを作成する

1. 「単語帳を選ぶ」でCSV/TSVを読み込む。
2. 出題範囲と問題数を指定する。
3. 出題方向とランダム出題の有無を選択する。
4. 画面右側のプレビューを確認する。
5. 印刷機能から問題用紙・解答用紙を出力する。

`Ctrl + O` でファイル選択、`Ctrl + Enter` で印刷操作、`?` でショートカット一覧を表示できます。

## 設計・実装上の工夫

### ローカル処理

選択した学習データはブラウザ上で読み込んで処理します。アプリケーション自体に教材データをサーバーへ送信する処理は設けていません。利用者が管理するファイルをその都度選択する方式です。

### CSV解析と出題処理

CSV/TSVの引用符付きフィールドを扱うパーサーをJavaScriptで実装し、読み込んだ行を出題用データに変換しています。ランダム出題にはFisher–Yatesシャッフルを使用し、選択した問題行から指定数を抽出します。

### プレビューと印刷

データから印刷用HTMLを生成し、`iframe` にプレビューを表示します。印刷用のCSSを分離し、問題用紙と解答用紙の表示・印刷に対応しています。

### ファイル構成

| ファイル | 主な役割 |
| --- | --- |
| `index.html` | 操作画面の構造 |
| `app.js` | ファイル読み込み、CSV解析、出題設定、画面制御 |
| `print.js` | 印刷用HTML・スタイルの生成、印刷操作 |
| `styles.css` | アプリケーション画面のデザイン |

**処理の流れ：** ファイル選択 → CSV/TSV解析 → 出題範囲・形式の指定 → 問題抽出 → 印刷用HTML生成 → プレビュー・印刷

## 現在の制約と今後の改善

- 社会モードは調整中であり、入力形式や表示の改善を進める予定です。
- CSV/TSVの自動判定や不正な入力に対する処理には、追加の検証が必要です。
- ランダム出題は、設定変更によるプレビュー更新時に再抽選されます。プレビューと別経路で生成した印刷結果の整合性は改善予定です。
- 単体テストおよびGitHub Actionsによる自動テストは今後整備する予定です。
- 印刷レイアウトはブラウザやプリンターの設定によって差が生じる場合があります。

## 利用上の注意

教材データは各自で用意し、著作権・利用条件を確認のうえ使用してください。実際の教材データは本リポジトリには含めていません。

現時点ではオープンソースライセンスを設定していません。リポジトリが公開されていることは、ソースコードの再利用や再配布の許可を意味するものではありません。
