# 小テストジェネレータ

CSV/TSV形式の学習データから、小テストと解答用紙を
自動生成するブラウザベースのWebアプリケーションです。

## 主な機能

- CSV/TSVファイルの読み込み
- 出題範囲・問題数の指定
- ランダム出題
- 英語・日本語の双方向出題
- 社会科向け問題形式への対応
- 印刷プレビュー
- 問題用紙・解答用紙の生成
- 複数テストの一括生成

## 使用技術

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 起動方法

`index.html` を対応ブラウザで開いてください。

サーバーの構築や追加ライブラリのインストールは不要です。
